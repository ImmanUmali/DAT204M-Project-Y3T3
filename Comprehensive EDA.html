Dataset Overview¶

This project uses the MerRec (Mercari Recommendation) dataset, a large-scale benchmark for consumer-to-consumer (C2C) recommendation systems introduced by Li et al. (2024). The dataset contains anonymized user interaction data from the Mercari e-commerce platform, including user activities, product information, session identifiers, timestamps, product categories, and other item attributes. It was designed to support research on large-scale recommendation systems.

References

  • Research Paper: https://arxiv.org/abs/2402.14230
  • Dataset Repository: https://huggingface.co/datasets/mercari-us/merrec

  • Contents: User interactions, product metadata, session information, timestamps, and product taxonomy.

Dataset Schema¶

The original MERREC dataset contains 21 attributes. For this project, only the columns relevant to product-level clustering were retained, reducing the dataset to 14 columns. Identifier columns that were redundant (e.g., category and brand IDs), sequence-related fields, size information, and shipping information were removed. Additionally, a new year_month column was added to preserve the source month after combining multiple monthly datasets.

The Cramér’s V function measures the strength of association between two categorical variables by applying a chi-square test and adjusting for sample size bias, producing a value between 0 and 1, where values closer to 0 indicate weak or no association and values closer to 1 indicate a strong relationship between categories.

def cramers_v(pdf, col1, col2):

    data = pdf[[col1, col2]].dropna()

    confusion_matrix = pd.crosstab(data[col1], data[col2])

    # Need at least 2 categories in each variable
    if confusion_matrix.shape[0] < 2 or confusion_matrix.shape[1] < 2:
        return np.nan

    chi2 = chi2_contingency(confusion_matrix)[0]
    n = confusion_matrix.values.sum()

    phi2 = chi2 / n
    r, k = confusion_matrix.shape

    phi2corr = max(0, phi2 - ((k - 1) * (r - 1)) / (n - 1))
    rcorr = r - ((r - 1) ** 2) / (n - 1)
    kcorr = k - ((k - 1) ** 2) / (n - 1)

    denom = min(kcorr - 1, rcorr - 1)

    if denom <= 0:
        return np.nan

    return np.sqrt(phi2corr / denom)

The correlation ratio (η, eta) function measures the strength of the relationship between a categorical variable and a numerical variable by comparing the variation of numerical values between different categories against the total variation in the dataset. The metric ranges from 0 to 1, where values closer to 0 indicate that category groups have similar numerical distributions (weak or no relationship), while values closer to 1 indicate that the numerical variable differs significantly across categories (strong relationship).

The function first removes missing values, separates the numerical measurements by category, and calculates the overall mean of the numerical variable. It then measures how much of the total variance is explained by differences between category groups using the ratio of between-group variance to total variance. A square root transformation is applied to return the final correlation ratio value, which represents the strength of association between the categorical and numerical variables.

This metric is useful for analyzing relationships such as whether product categories, brands, or item conditions influence numerical behaviors like price, views, likes, purchases, or user engagement metrics.

def correlation_ratio(pdf, cat_col, num_col):
    data = pdf[[cat_col, num_col]].dropna()

    categories = pd.Categorical(data[cat_col])
    measurements = data[num_col].values

    grand_mean = np.mean(measurements)

    numerator = 0
    denominator = np.sum((measurements - grand_mean) ** 2)

    for category in categories.categories:
        values = measurements[categories == category]

        if len(values) == 0:
            continue

        numerator += len(values) * (np.mean(values) - grand_mean) ** 2

    if denominator == 0:
        return np.nan

    return np.sqrt(numerator / denominator)

The correlation ratio (η) analysis between categorical features and product price shows that brand_name has the strongest relationship with price (η = 0.454), suggesting that certain brands are associated with different pricing levels and may significantly influence product value.

Among the category variables, c2_name shows the highest association with price (η = 0.321), followed by c1_name (η = 0.254) and c0_name (η = 0.118). This indicates that more specific product categories tend to provide better separation of price ranges, as detailed subcategories capture differences between product types more effectively than broad categories.

In contrast, item_condition_name has almost no relationship with price (η = 0.020), suggesting that condition labels such as new, good, fair, or poor do not strongly determine the listed price in this dataset. Similarly, event_id shows a very weak association with price (η = 0.036), indicating that user interaction types are largely independent of product pricing.

Overall, the results suggest that brand and detailed product categories are more informative predictors of price, while item condition and user behavior events contribute limited information for explaining price variation.
